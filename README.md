# Fresh Fruit

Nền tảng thương mại điện tử trái cây tươi, cấu trúc MERN + Vite/Tailwind. Task 01 tập trung vào nền tảng project, routing, health check và Home responsive.

## Chạy local

```bash
npm install
npm --prefix fe install
npm --prefix be install
npm run dev
```

Frontend chạy ở `http://localhost:5173`, backend ở `http://localhost:5000`. MongoDB chỉ được kết nối khi có `MONGODB_URI`.

# Folder structure

`fe/` chứa frontend React/Vite theo components, layouts, pages, routes, services, contexts, hooks, utils, config và data. `be/` chứa Express theo config, middleware, modules, routes và utils. Các module nghiệp vụ sẽ được triển khai theo từng task, không tạo skeleton rỗng hàng loạt.
